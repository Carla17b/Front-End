Desenvolvimento Web Frontend

Sobre o Aprendizado de HTML

O HTML é a base de qualquer aplicação na World Wide Web. É através dele que estruturamos todo o conteúdo que o usuário consome, utilizando tags semânticas para dar significado aos textos, imagens e links.

Aprender a organizar as pastas e os arquivos corretamente é um passo fundamental para manter o projeto limpo e escalável, facilitando também o trabalho em equipe através do controle de versão com o Git.

Nesta etapa, o foco principal é compreender a anatomia de um documento HTML e como os navegadores interpretam essas tags para renderizar a interface final para o cliente.

Tecnologias Utilizadas e Próximos Passos

Lista de Tecnologias Aprendidas:

  • HTML5 (Estruturação de conteúdo)
  • CSS3 (Estilização e design)
  • JavaScript (Lógica e interatividade)
  • Git & GitHub (Controle de versão e repositórios)

Passos do Projeto:

  1. Realizar a pesquisa teórica sobre conceitos de Frontend e W3C.
  2. Organizar a estrutura de diretórios do projeto de forma padronizada.
  3. Criar a primeira página HTML estruturada com tags básicas.
  4. Realizar o commit e enviar as alterações para o repositório remoto.
