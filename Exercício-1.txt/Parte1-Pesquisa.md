# Exercício 1 - Parte 1: Pesquisa

## 1. O que é Frontend?
O **Frontend** é a interface direta de uma aplicação com o usuário. Trata-se de tudo aquilo que você consegue ver, interagir e navegar em um site ou aplicativo web (botões, menus, imagens, animações e formulários). O desenvolvedor frontend é responsável por transformar o design de uma tela em um código funcional e garantir uma boa experiência do usuário (UX).

---

## 2. O que é Cliente x Servidor?
Esse conceito define o modelo de arquitetura mais comum na internet, onde as tarefas são divididas entre quem pede e quem responde:

* **Cliente (Client):** É a ponta que consome o serviço. Geralmente é o navegador web do usuário (Google Chrome, Firefox, Safari) ou um aplicativo de celular. Ele faz **requisições (requests)** para acessar páginas ou dados.
* **Servidor (Server):** É um computador potente (ou sistema) remoto que armazena os arquivos do site, bancos de dados e regras de negócio. Ele processa a requisição feita pelo cliente e envia de volta uma **resposta (response)**.

---

## 3. Qual é o papel de HTML, CSS e JavaScript?
Essas são as três tecnologias fundamentais da Web que rodam no lado do cliente:

* **HTML (HyperText Markup Language):** É a linguagem de marcação que define a **estrutura e o conteúdo** da página (títulos, parágrafos, imagens e links).
* **CSS (Cascading Style Sheets):** É a linguagem de estilos usada para dar **aparência e design** ao HTML (cores, fontes, espaçamentos e layouts responsivos).
* **JavaScript:** É a linguagem de programação que adiciona **interatividade e dinamismo** à página (comportamento de botões, atualizações de conteúdo em tempo real e animações complexas).

---

## 4. O que é W3C?
O **W3C (World Wide Web Consortium)** é um consórcio internacional fundado por Tim Berners-Lee (o criador da Web) com o objetivo de regulamentar e criar **padrões técnicos para a World Wide Web**. É graças às diretrizes e recomendações do W3C que tecnologias como HTML e CSS funcionam da mesma maneira em qualquer navegador moderno, garantindo uma web aberta, acessível e universal.
