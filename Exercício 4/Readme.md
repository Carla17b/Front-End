# Exercício 4 — TechStore (Loja Fictícia)

Projeto de uma loja virtual de periféricos de informática criada para o exercício de Frontend.

## Descrição do Projeto
A TechStore é uma loja fictícia focada em produtos para setups de estudo e trabalho. O projeto contém navegação entre páginas e componentes estruturados com Flexbox em um arquivo CSS externo.

## Estrutura de Arquivos
- `index.html`: Página inicial apresentando a loja e os produtos em destaque.
- `produtos.html`: Catálogo com a listagem dos itens disponíveis e preços.
- `contato.html`: Canal de atendimento ao cliente.
- `css/style.css`: Estilização global do projeto (sem o uso de CSS inline ou interno).
- `img/`: Imagens do projeto e capturas de tela do site.
