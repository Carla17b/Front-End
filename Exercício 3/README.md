# Exercício 3 - Estrutura de Landing Page e CSS Externo

Este diretório contém a fase inicial do Exercício 3, focado na aplicação prática de tags estruturais do HTML5 e na modularização correta de estilos por meio de folhas de estilo externas.

## Objetivo
Desenvolver uma landing page estruturada de forma semântica e estilizada exclusivamente via arquivo `style.css` externo, respeitando a separação de responsabilidades no desenvolvimento web.

## Estrutura do Projeto
* `index.html`: Arquivo de marcação contendo cabeçalho, menu, conteúdo principal (hero, sobre, recursos) e rodapé.
* `css/style.css`: Arquivo focado nas regras de estilização visual da interface.
