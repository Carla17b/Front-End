# Estrutura do Projeto

## Diretotório Raiz e Subpastas

*   **`FRONT-END/`**: É a pasta principal (raiz) que engloba todo o projeto de desenvolvimento frontend.
*   **`Exercício-1.txt/`**: Uma pasta principal do exercício (nota-se o sufixo `.txt` no nome da pasta, mas ela funciona como um diretório neste ambiente).
    *   **`Parte2-Estrutura de Projeto./`**: Subpasta destinada à segunda parte do exercício, focada na organização estrutural de uma aplicação web.
        *   **`CSS/`**: Pasta exclusiva para armazenar os arquivos de estilização e identidade visual.
        *   **`HTML/`**: Pasta que armazena os arquivos de marcação estrutural e conteúdo das páginas.
        *   **`JS/`**: Pasta reservada para os scripts e arquivos de lógica de programação em JavaScript.
        *   **`README.md/`**: Uma pasta criada com o nome de um arquivo Markdown (provavelmente de forma acidental), que atualmente contém arquivos de pesquisa interna.
    *   **`imgs/`**: Pasta localizada na raiz do exercício para centralizar e organizar todas as imagens e assets visuais utilizados no projeto.

---

## Arquivos do Projeto

*   **`style.css`** *(dentro de CSS/)*: Arquivo contendo as regras de estilo (cores, fontes, layouts e espaçamentos) que definem a aparência visual da página.
*   **`index.html`** *(dentro de HTML/)*: O arquivo principal da página web. Ele contém a estrutura semântica (textos, links, divisões) que o navegador vai ler.
*   **`javascript.js`** *(dentro de JS/)*: Arquivo de script responsável por adicionar interatividade, animações ou comportamentos dinâmicos na interface.
*   **`Pesquisa.md`** *(dentro da pasta README.md/)*: Arquivo de texto em formato Markdown contendo anotações ou dados da pesquisa realizada para a Parte 2.
*   **`Parte-1-Pesquisa.md`** *(na raiz de Exercício-1.txt)*: Arquivo Markdown que documenta a primeira parte do exercício (provavelmente contendo as definições de Frontend, Cliente/Servidor, W3C, etc.).
*   **`README.MD`** *(na raiz de Exercício-1.txt)*: O arquivo de documentação principal do repositório, utilizado para guiar o leitor sobre o que é o projeto e como ele está estruturado (este arquivo que você está lendo).
